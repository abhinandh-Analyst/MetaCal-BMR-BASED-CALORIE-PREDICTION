# 🍽️ Calorie Prediction Using Machine Learning

📌 Project Overview
This project predicts the number of calories based on nutritional and personal features using Machine Learning regression models.  
It helps in diet planning and health monitoring by giving accurate calorie estimation.

🎯 Problem Statement
Manually calculating calorie requirements is difficult and often inaccurate.  
This project aims to automate calorie prediction using a trained ML model.

 📊 Dataset
- Nutritional dataset
- Contains features like:
  - Protein
  - Carbohydrates
  - Fat
  - Fiber
  - etc.
- Target variable: Calories

 🧠 Models Used
- Linear Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- AdaBoost

🏆 Best Model
- Random Forest Regressor
- Achieved R² score ≈ 0.98

🛠️ Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Joblib
