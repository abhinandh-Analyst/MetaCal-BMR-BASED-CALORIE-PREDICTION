# 🤖 MetaCal - Calorie Prediction (Machine Learning)

## 📊 Overview

This project predicts daily calorie intake using machine learning based on health and lifestyle data.

## 🎯 Objectives

* Predict calorie requirements accurately
* Automate manual calorie tracking
* Build an end-to-end ML pipeline

## 🛠 Tools Used

* Python
* Scikit-learn
* Pandas, NumPy

## ⚙️ ML Process

* Data Cleaning & Preprocessing
* Outlier Detection (IQR)
* Feature Selection
* Model Training & Evaluation

## 🤖 Models Used

* Linear Regression
* Decision Tree
* Random Forest (Best Model)
* Gradient Boosting

## 📊 Performance

* R² Score: ~0.95
* MAE & RMSE used for evaluation

## 🚀 Deployment

* Model saved using Joblib
* Used for real-time prediction

## 🔍 Key Insights

* Lifestyle and BMR strongly influence calorie needs
* Random Forest provided best performance

## 📁 Files Included

* Jupyter Notebook (.ipynb)
* Dataset
